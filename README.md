# The Arcane Tower Adventure

A fantasy text-based adventure game where the player must collect seven legendary magical artifacts before confronting the evil sorcerer Malachar in the Throne Room.

## 🚀 Project Overview
This project was developed as part of my Python coursework at SNHU. It demonstrates my ability to use:
- **Python Functions:** To organize logic into reusable blocks.
- **Dictionaries:** To map out the game world and room connections.
- **User Input Handling:** To process player commands and manage inventory.
- **Conditional Logic:** To manage game states and "Win/Loss" conditions.

## 🛠 How to Run
1. Ensure you have Python installed on your computer.
2. Download the `TextBasedGame.py` file.
3. Open your terminal or command prompt.
4. Navigate to the folder and run:
   `python TextBasedGame.py`

## 📈 What I Learned
While building this, I learned how to manage complex nested dictionaries and how to structure a "Game Loop." I also practiced debugging logic errors related to player movement and item collection.
